# Step 4/5 -- evaluation
# Deliberately pinned, not an oversight: leaving this unpinned resolves to
# ragas 0.4.3 in a clean install, which has a hard import-time crash --
# `from ragas.llms.base import BaseRagasLLM` (used directly by
# app/eval/ragas_llm.py) raises ModuleNotFoundError on
# langchain_community.chat_models.vertexai, confirmed reproducible inside
# a real container build, not just locally. app/eval/ragas_llm.py's
# LocalQwenRagasLLM is also written specifically against 0.1.21's
# BaseRagasLLM interface (generate_text/agenerate_text abstract methods,
# confirmed present in 0.1.21 and unreachable at all in 0.4.3 due to the
# crash above). Do not bump this without re-verifying
# scripts/run_ragas_comparison.py actually runs end-to-end, not just that
# ragas imports cleanly.
ragas==0.1.21

# Resolved by `pip show` inside a container built with the ragas==0.1.21

# drift over time.
pydantic==2.13.4
